New here? How an assessment works
A security assessment follows five steps: 1) Scope — decide exactly what you may test (autopilot limits itself to the target's host). 2) Map — crawl to find pages, forms, and parameters. 3) Test — probe every input with passive and active checks. 4) Review — read findings worst-first; expand "Learn about this" on each. 5) Report — use the Report button in the header to export an HTML write-up.
